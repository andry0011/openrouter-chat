# Журнал проекта: OpenRouter Test Chat → аналог Umnik.ai

Документ описывает видение, архитектуру и текущее состояние проекта — для передачи полного контекста Claude Code или любому, кто продолжит работу.

## Видение продукта

Строим **российский агрегатор нейросетей**, вдохновлённый **umnik.ai** — один сайт с подпиской, где пользователь получает доступ ко всем топовым моделям (текст/картинки/видео) без VPN и зарубежных карт, через единый API-ключ OpenRouter на бэкенде.

Референс для UX (изучен подробно, воспроизведён частично):
- **umnik.ai** — сайдбар (Новый чат / Мои генерации / Генератор / категории по типу контента), плашки-провайдеры с логотипами + пилюли конкретных версий модели под ними, полноэкранный каталог «Все нейросети» с карточками (иконка, цена, описание), токеновая система оплаты (4 тарифа), автовозврат токенов при сбое генерации.

## Текущая архитектура

- **Бэкенд:** Node.js + Express (`server.js`) — прокси к трём API OpenRouter (`/chat/completions` для текста, `/images` для картинок, `/videos` для видео, асинхронно с поллингом статуса)
- **Фронтенд:** ваниль HTML/CSS/JS (`public/`), без фреймворков, оформление в стиле Claude (тёплые тона) + элементы UX от Umnik
- **Хранение:** файловая БД (`data/users.json`, `data/model-stats.json`) — простое JSON-хранилище вместо SQL, осознанный выбор для MVP (не требует нативной компиляции на сервере)
- **Аутентификация:** email/пароль, bcrypt, JWT в httpOnly-куке

## Что уже реализовано (по волнам/этапам)

### Волны генерации
- ✅ **Волна 1** — текстовые модели (весь каталог OpenRouter)
- ✅ **Волна 2** — vision (загрузка изображений для анализа моделью)
- ✅ **Волна 3** — генерация изображений (`/api/v1/images`, отдельный каталог моделей)
- ✅ **Волна 4** — генерация видео (`/api/v1/videos`, асинхронно: создание задачи → поллинг статуса каждые 8 сек → скачивание готового ролика)

### Пейвол / монетизация (демо, без реальных денег)
- Тизер-механика: ответ генерируется в фоне (токены тратятся по-настоящему), но скрыт до "оформления подписки"
- Тарифы: 1990₽/мес, 4770₽/3 мес (с недельной ценой-якорем ~367₽/неделя)
- Работает для текста, картинок и видео одинаково (блюр + оверлей с CTA)

### Аккаунты (Этап 1)
- Регистрация/вход по email+паролю
- Pro-статус хранится на сервере, привязан к аккаунту (не к браузеру) — работает на любом устройстве
- Кнопка аккаунта в шапке, logout

### UI в стиле Umnik
- Кликабельные иконки провайдеров (Claude, GPT, Gemini, DeepSeek, Meta/Llama, Kling, Nano Banana, GPT Image, Seedance/ByteDance, Suno) — **реальные официальные логотипы**, загружены пользователем вручную и лежат в `public/icons/*.png`
- На пустом экране нового чата: крупные плашки-провайдеры (72px, с активной подсветкой рамкой + подпись снизу + пружинистый hover-подскок) → под ними автоматически появляются **пилюли всех реальных версий** этого провайдера, подтянутые из каталога OpenRouter
- Полноэкранная модалка **«Все нейросети»** — вкладки Текст/Картинка/Видео, сетка карточек с реальными ценами OpenRouter, иконками и короткими описаниями (у топ-моделей — вручную написанные, у остальных — общие по категории)
- Тихий сбор статистики использования моделей на сервере (`/api/model-stats`) — **не отображается**, ждём порога 10 000+ использований одной модели, тогда добавим счётчик на карточку

### Работа с файлами (Excel/ZIP/изображения)
- Drag-and-drop + кнопка прикрепления
- Изображения → vision-анализ (base64 в сообщении)
- Excel (.xlsx/.xls) → парсится в браузере (SheetJS), превращается в markdown-таблицу
- ZIP → распаковывается в браузере (JSZip), текстовые файлы читаются как текст, **Excel-файлы внутри архива тоже парсятся** (не просто пропускаются)
- **Специальная логика для строительных смет** (формат «ГРАНД-Смета»): автоматически находит итоговую сумму по правилу «строка с текстом ровно "Итого" → число в столбце L», с двумя уровнями резервных вариантов (протестировано на реальных 90 файлах смет, дало точное совпадение с ручной проверкой — 136 268 087 ₽). Если это похоже на смету — в текст модели уходит только итог, не вся таблица (экономит токены); в конце автоматически считается общая сумма по всем распознанным сметам в архиве.

### Точность стоимости
- Используется параметр `usage: {include: true}` в запросах к OpenRouter — сервер возвращает реальную $-стоимость вместо того, чтобы мы сами считали по таблице цен (это чинит баг с отрицательными числами у мета-моделей типа "Auto Router")

- **Деплой сейчас (ручной, до перехода на Claude Code/git):**
  ```bash
  # На своём компьютере:
  scp "путь\к\архиву.zip" root@82.97.246.95:/root/openrouter-chat-vX.zip
  # На сервере (после ssh root@82.97.246.95):
  cd /root
  unzip -o openrouter-chat-vX.zip -d /root/openrouter-chat-new
  ```

## Ключевые уроки/грабли этого проекта

- Shared-хостинг (Beget) не подходит для постоянно работающих Node.js процессов — нужен VPS
- На VPS всегда проверять ОБА файрвола (облачный + `ufw` внутри ОС)
- Новые домены с "AI" в названии могут попадать под антиспам-блокировку реестра
- ZIP-архивы с кириллицей в именах файлов ломают стандартный `unzip` — нужен Python (`zipfile`) или JSZip в браузере
- Для финансовых расчётов (суммы смет) — никогда не просить ИИ складывать числа через рассуждение, только детерминированный код
- OpenRouter возвращает реальную стоимость только при явном `usage: {include: true}` в запросе — без этого параметра расчёт цены по статичной таблице может уйти в минус для мета-моделей
