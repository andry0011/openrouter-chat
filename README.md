# OpenRouter Test Chat

Простое веб-приложение для тестирования любых моделей через [OpenRouter](https://openrouter.ai):
выбор модели, стриминг ответа, подсчёт токенов и стоимости, история чатов.
Оформление — в духе интерфейса Claude (тёплый кремовый фон, терракотовый акцент).

## Структура

```
openrouter-chat/
├── server.js          # бэкенд: Express, проксирует запросы к OpenRouter
├── package.json
├── .env.example        # опционально: свой ключ можно зашить на сервере
└── public/
    ├── index.html
    ├── style.css
    └── app.js           # вся логика фронтенда (без фреймворков)
```

## Запуск локально

```bash
cd openrouter-chat
npm install
npm start
```

Откройте `http://localhost:3000`. Нажмите «Настройки» → вставьте свой ключ
(`sk-or-v1-...` из https://openrouter.ai/workspaces/default/keys) → «Сохранить».
Дальше выбирайте модель сверху и общайтесь.

Ключ хранится **только в localStorage вашего браузера**. При каждом запросе он
уходит в заголовке `x-openrouter-key` на ваш собственный бэкенд, а тот сразу
пересылает его в OpenRouter — на сервере ключ нигде не сохраняется.

Если хотите зашить ключ на сервере (например, для приложения, которым
пользуетесь только вы) — скопируйте `.env.example` в `.env` и впишите
`OPENROUTER_API_KEY=...`. Тогда поле в настройках можно оставить пустым.

## Что умеет

- Выбор модели из полного списка моделей OpenRouter (поиск по названию/id), с ценой за 1M токенов.
- Стриминг ответа (текст печатается по мере генерации), как в обычном чате.
- Подсчёт токенов и примерной стоимости каждого ответа + общий счётчик по сессии.
- Проверка ключа и баланса кнопкой в настройках (дергает `/api/auth/key` у OpenRouter).
- Несколько параллельных чатов с историей (хранится в localStorage).
- Настройка temperature.
- Адаптивная вёрстка (мобильный вид со сдвижным сайдбаром).

## Деплой на свой сайт/сервер

Это обычное Node.js-приложение — подходит для Render, Railway, VPS,
Fly.io и т.д. Нужно только:
1. `npm install`
2. `npm start` (или через pm2/systemd)
3. Открыть порт (по умолчанию 3000, меняется через `PORT` в `.env`)

Прокси нужен, чтобы обойти CORS-политику OpenRouter при прямых
запросах из браузера и чтобы контролировать стриминг на своей стороне —
без него часть браузеров блокирует прямые fetch-запросы к сторонним API.

## Как превратить в мобильное приложение

Бэкенд и фронтенд уже разделены, поэтому у вас есть два пути:

**Вариант А — обёртка (быстрее всего).**
Задеплойте `server.js` на любой хостинг (Render/Railway/VPS), получите
публичный URL, и оберните его в WebView через
[Capacitor](https://capacitorjs.com/) или Cordova:
```bash
npm install @capacitor/core @capacitor/cli
npx cap init
# укажите server.url = https://ваш-домен в capacitor.config.json
npx cap add ios
npx cap add android
```
Получите нативные iOS/Android-проекты, открывающие ваш сайт как приложение —
без переписывания логики.

**Вариант Б — нативная логика.**
`app.js` уже разделяет UI и работу с API (`fetch('/api/chat', ...)`),
так что для React Native/Flutter достаточно перенести:
- вызовы `/api/models`, `/api/chat`, `/api/key-check` (или дергать
  OpenRouter напрямую из мобильного клиента),
- логику парсинга SSE-потока (`streamAssistantReply` в `app.js`),
- расчёт стоимости (`estimateCost`).

## Изменение цветовой схемы / бренда

Все цвета вынесены в CSS-переменные в начале `style.css` (`:root { --accent: ... }`) —
поменяете один раз, а не по всему файлу.
